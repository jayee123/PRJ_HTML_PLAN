1. 碳排放量計算公式

溫室氣體盤查採用 GHG Protocol 通用公式，將每一項排放源的活動數據換算為 CO2 當量後加總：

Total CO2e  =  Σi=1..n ( ADi × EFi × GWPi )
符號名稱說明
ADActivity Data 活動數據用電度數(kWh)、用水量(m³)、油品用量(L)、紙張用量(kg) 等實際發生量
EFEmission Factor 排放係数每單位活動量產生的溫室氣體量
GWPGlobal Warming Potential 全球暖化潛勢將 CH4、N2O 等氣體換算為 CO2 當量的權重
n排放源數量企業盤查範圍內所有排放類別加總

對應本系統資料表

台灣官方公告排放係数（台電電力係数、能源局油品係数等）已是 EF × GWP 合併值，系統直接以合併係数相乘：

CO2e (kg)  =  AD × (EF × GWP 合併係数)
公式符號系統資料表欄位
ADemission_records.amount／IoT 的 energy_kwh、water_liter
EF × GWP 合併係数carbon_factors.coefficient（如電力 0.4940 kgCO2e/kWh）
CO2eemission_records.emission_kg／iot_logs.carbon_kg
def calculate_co2e(activity_data, emission_factor, gwp=1.0):
    # Total CO2e = Σ(AD × EF × GWP)
    return float(activity_data) * float(emission_factor) * float(gwp)

2. 台灣碳費制度分析

依環境部 2024/08/29 公告「碳費三子法」（碳費收費辦法、自主減量計畫管理辦法、增量抵換管理辦法）及 2024/10/07 公告費率：

2.1 徵收對象與門檻

  • 徵收對象：年溫室氣體排放量達 2.5 萬公噸 CO2e 以上之電力、燃氣供應業及製造業（首批約 281 家企業、500 座工廠）
  • 起扣額度 K 值：25,000 公噸 CO2e（高碳洩漏風險行業 K = 0）

2.2 徵收費率

費率別金額 (NT$/tCO2e)適用條件
一般費率300未提出自主減量計畫
優惠費率 A50自主減量計畫符合「行業別指定削減率」
優惠費率 B100自主減量計畫符合「技術標竿指定削減率」

官方規劃每 2 年檢討調升，2030 年上看 1,200–1,800 元/噸。

2.3 高碳洩漏風險排放量調整係数

階段調整係数
第一期0.2
第二期0.4
第三期0.6

2.4 計算公式

收費排放量 = (年排放量 − K值) × 調整係数  (一般行業，K=25,000噸，係数=1)
收費排放量 = 年排放量 × 調整係数  (高碳洩漏風險，K=0，係数=0.2/0.4/0.6)
碳費 (NT$) = 收費排放量(tCO2e) × 徵收費率(NT$/tCO2e)

2.5 徵收時程

年度動作
2025（114年）試申報，不繳費
2026（115年）依 2025 年排放量與適用費率，正式繳交碳費
之後逐年依當年度排放量申報繳費

3. 碳費試算與預測設計

設計原則：資料量小、需可解釋可稽核 → 採 scikit-learn 一元線性迴歸（Linear Regression）抓月排放量趨勢外推年度排放量，而非 ARIMA / LSTM 等複雜模型，避免過度配適且方便向填報人員說明。資料不足 2 個月時自動退回「月平均 × 12」法。

3.1 演算法流程與預測公式

Step 1：彙總今年度至今(YTD)每月碳排放量（emission_records + iot_logs）

X = 月份索引 [1, 2, ... n]  ，  y = 對應月排放量(kg)
model = LinearRegression().fit(X, y)  →  斜率(趨勢) + R²(可信度)
預估全年排放量  =  YTD實際值  +  Σ model.predict(剩餘月份)

Step 4：將「預估全年排放量」代入第 2.4 節台灣碳費公式，試算年度預估碳費。資料 < 2 個月時無法擬合迴歸線，改用 平均月排放量 × 12。

def forecast_annual_emission(monthly_emissions_kg):
    months = [float(m) for m in monthly_emissions_kg if m is not None]
    n = len(months); ytd = sum(months)
    if n < 2:
        return {'method': 'average_x12', 'projected_annual_emission_kg': ytd / n * 12, ...}

    X = np.arange(1, n + 1).reshape(-1, 1)        # 月份索引
    y = np.array(months)                           # 月排放量
    model = LinearRegression().fit(X, y)
    r2 = model.score(X, y)
    remaining = np.clip(model.predict(np.arange(n+1, 13).reshape(-1,1)), 0, None)
    projected = ytd + float(remaining.sum())        # YTD + 剩餘月份預測值
    return {'method': 'linear_regression', 'trend_slope_kg_per_month': model.coef_[0],
            'r2_score': r2, 'projected_annual_emission_kg': projected, ...}

CREATE TABLE carbon_fee_forecasts (
  id INT AUTO_INCREMENT PRIMARY KEY,
  forecast_year INT NOT NULL,
  forecast_method VARCHAR(30) NOT NULL DEFAULT 'linear_regression',
  basis_months INT NOT NULL,
  ytd_emission_kg DECIMAL(14,2) NOT NULL,
  avg_monthly_emission_kg DECIMAL(14,2) NOT NULL,
  trend_slope_kg_per_month DECIMAL(10,2) NOT NULL DEFAULT 0,
  r2_score DECIMAL(5,3) NULL,
  projected_annual_emission_kg DECIMAL(14,2) NOT NULL,
  rate_tier VARCHAR(20) NOT NULL DEFAULT 'general',
  high_leakage_risk TINYINT(1) NOT NULL DEFAULT 0,
  adjustment_coefficient DECIMAL(4,2) NOT NULL DEFAULT 1.00,
  k_threshold_ton DECIMAL(10,2) NOT NULL DEFAULT 25000.00,
  chargeable_emission_ton DECIMAL(12,2) NOT NULL DEFAULT 0,
  applicable_rate_ntd DECIMAL(10,2) NOT NULL DEFAULT 300.00,
  estimated_fee_ntd DECIMAL(14,2) NOT NULL DEFAULT 0,
  exceeds_threshold TINYINT(1) NOT NULL DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_forecast_year (forecast_year)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

7. 限制與免責聲明

  • 本系統碳費試算僅供內部管理決策參考，非環境部核定之正式碳盤查／查證數據，不能作為法定申報依據。
  • 正式申報須依「溫室氣體排放量盤查登錄及查驗管理辦法」完成第三方查驗，本系統不執行查驗流程。
  • 台灣碳費費率、門檻及係数將依環境部後續公告調整（每 2 年檢討一次），系統常數需隨法規更新維護。
  • 預測採 scikit-learn 一元線性迴歸，僅能捕捉線性趨勢；若排放量有明顯季節性或非線性成長，預估值會有誤差，建議每月覆核並參考 r2_score 判斷趨勢線可信度。
  • 本分析僅涵蓋台灣國內碳費制度，不含歐盟 CBAM、ISO 14064 國際查證等跨國規範。
